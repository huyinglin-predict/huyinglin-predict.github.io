1. _localWebNative (LocalWebNative) - 无校验接口

openH5UrlByHwBrowser(superLink, startmode) 无校验

在华为浏览器中打开任意 URL。参数: superLink=目标URL, startmode=启动模式(默认'cct')

shareReport(data) 无校验

触发分享面板。参数: data.shareUrl, data.query, data.imageUrl

getDeepResearchAttach(param) 无校验

返回 deepResearchAttach 对象 (可能包含敏感数据)

onRegenerateResearchFiles(param) 无校验

触发重新生成深度研究文件。参数: param (可选字符串)

closeOption() / fullScreenOption() / collapseScreenOption() 无校验

控制分屏 UI 布局

2. HiSearchNative (父类 CustomWebJsBridge) - 混合校验

openDeeplinkOrH5(bundleName, deeplink, h5) 无校验

打开 deeplink 或 H5 URL。参数: bundleName, deeplink, h5

jumpToShoppingPage(queryId) 无校验

跳转识图购页面。参数: queryId

openAppWithDeepLink(deeplink, pkgname) 有校验

启动目标应用。参数: deeplink=目标URI, pkgname=目标包名。需要白名单页面调用。

checkAppInstalled(pkgname) 有校验

检查应用是否安装。参数: pkgname=目标包名

reportEvent(eventid, value) 有校验

上报事件。参数: eventid=事件ID, value=JSON字符串

onBackPressed() 有校验

返回/退出。无参数。

3. HiSearchNative (子类) - 有校验接口

splitScreenAndJump(superLink) 有校验

分屏跳转。参数: superLink=目标链接

openIap(params) 有校验

打开计费页。参数: params={agentid, agentStatus, accountType, transBuffer}

4. 有校验接口 - 批量测试 (白名单页面下才能成功)

在 injected URL 页面下，有校验接口应返回 false/不执行；在白名单页面下应正常执行
