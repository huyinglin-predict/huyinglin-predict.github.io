关键发现: 父类 CustomWebJsBridge 中定义的 openDeeplinkOrH5 / jumpToShoppingPage 因 CustomWebPage.ets 用同名 HiSearchNative 覆盖注册且新 methodList 未包含这两个方法， 实际未暴露给 JS，调用会报 "is not a function"。
HiVoiceInterface 风险: WebViewPage.ets:167 和 WebviewInterface.ets:246 注册 HiVoiceInterface 时 只传了3个参数(obj, name, methodList)，未传第5个参数 methodsPermission， 意味着任何URL的H5页面都能调用这4个方法，无框架层URL白名单保护。 其中 getUid() 直接返回用户UID(敏感数据)，shareH5() 接收任意JSON触发分享流程。
无白名单校验 - 应用JSBridge
有白名单校验 - 应用JSBridge
系统级接口 - 非应用注册

1. _localWebNative (LocalWebNative) - 全部无校验

实际暴露 9 个方法: closeOption, collapseScreenOption, download, fullScreenOption, getDeepResearchAttach, onBackPressed, onRegenerateResearchFiles, openH5UrlByHwBrowser, shareReport

openH5UrlByHwBrowser(superLink, startmode) 无校验

在华为浏览器中打开任意 URL。参数: superLink=目标URL, startmode=启动模式(默认'cct')

shareReport(data) 无校验

触发分享面板。参数: data 对象含 shareUrl/query/imageUrl

getDeepResearchAttach(param) 无校验

返回 deepResearchAttach 对象 (可能包含敏感数据)。可传 param 参数

onRegenerateResearchFiles(param) 无校验

触发重新生成深度研究文件。参数: param (可选)

download(url) 无校验

触发文件下载。参数: url=下载地址

closeOption() / fullScreenOption() / collapseScreenOption() / onBackPressed() 无校验

控制 UI 布局/返回

2. HiSearchNative - 全部有白名单校验

实际暴露 6 个方法: checkAppInstalled, onBackPressed, openAppWithDeepLink, openIap, reportEvent, splitScreenAndJump

openAppWithDeepLink(deeplink, pkgname) 有校验

启动目标应用。参数: deeplink=目标URI, pkgname=目标包名。需要白名单页面调用。

checkAppInstalled(pkgname) 有校验

检查应用是否安装。参数: pkgname=目标包名

reportEvent(eventid, value) 有校验

上报事件。参数: eventid=事件ID, value=JSON字符串

onBackPressed() 有校验

返回/退出。无参数。

splitScreenAndJump(superLink) 有校验

分屏跳转。参数: superLink=目标链接

openIap(params) 有校验

打开计费页。参数: params={agentid, agentStatus, accountType, transBuffer}

3. HiVoiceInterface - 全部无 methodsPermission 校验

暴露 4 个方法: shareH5, closeH5, getUid, shareH5ToRubikCube。注册时未传 methodsPermission 参数，任何 URL 均可调用。

来源: WebViewPage.ets:167 / WebviewInterface.ets:246 (registerJavaScriptProxy 只传3个参数)

getUid() 无校验 敏感数据

直接返回用户 UID 字符串。无任何白名单校验，任意 H5 页面可调用获取用户标识。

shareH5(shareInfoStr) 无校验

接收 JSON 字符串，解析为 ShareInfo 对象(sharedWord/sharedH5LinkUrl/sharedTitle/sharedContent/sharedPic)，触发分享流程并加载图片 URL。可注入任意分享内容。

closeH5() 无校验

关闭当前 Web 页面 (NavigationUtils.pop)。任意 H5 可强制关闭页面。

shareH5ToRubikCube() 无校验

触发分享数据到魔方 (shareData)，返回 boolean。需先调用 shareH5 设置分享内容。

4. 系统级接口 (非应用 JSBridge)

这些由 Web 组件框架注入，不属于应用 registerJavaScriptProxy 注册。仅供探测，不属于本次审计范围。

arkMessager.postMessage(data) 系统级

Web 组件框架消息通道

ArkWebContentChangeDetector.reportContentChange() 系统级

Web 组件内容变更检测

arkWeb (滚动条区域信息) 系统级

系统对象，含 scrollbarAvoidAreaTop/Bottom 数字属性
